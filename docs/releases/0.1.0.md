# Photoproof 0.1.0

Foundation release candidate. This record describes the unsigned local
candidate; it is not approved for publication until the signing, notarization,
model-ready, native-platform, and staged-update gates in
`docs/DESKTOP-RELEASE.md` pass.

## Changes

- Explicit startup, degraded, repair, and bounded-shutdown lifecycle.
- Backend-authoritative model/runtime state and serialized operations.
- Resource-governed ingest, structured journey monitoring, and health actions.
- Linux DEB, RPM, and AppImage foundation artifacts with installed smoke.
- Checked-in three-OS quality, package, NVIDIA, and production-release
  workflows; remote and signed receipts remain pending.

## Database compatibility

This build writes database schema 16. It upgrades older supported databases
only after creating and verifying a pre-upgrade backup, and refuses to open a
database written by a newer application.

## Rollback

Stop offering the release. If the database migrated, restore the pre-upgrade
backup before opening it with older code. Ship the known-good code as a newly
signed higher patch version; do not offer an unsigned or lower version.
