Library
Watched folders
  • Register and remove watched root folders; everything beneath is indexed automatically [M1]
  • Live filesystem watcher while running - debounced, mid-copy-safe, rename-pairing - plus reconciliation scans at launch, on volume mount, every 6 hours, and after sleep [M1]
  • Drag a folder onto the window to add it; "Add folder…" button and context-menu row on the rail
  • Removing a root preserves its journals; re-adding it recovers everything with zero re-hashing
  • Junk never enters the library: hidden files, caches, sync partials, oversized files, and unknown formats are excluded during walks
  • Cloud placeholder files (iCloud / OneDrive dataless stubs) are detected and skipped, then ingested when they hydrate
Identity & ingest
  • Images are known by the BLAKE3 hash of their bytes, never by path - move and rename freely, annotations follow the pixels [M1]
  • Resumable, idempotent ingest at 50k+ scale: interruption-safe, restart-safe, proven against real kill -9 mid-ingest [M1]
  • Byte-identical duplicates collapse to one image with every known location and a single journal
  • Overwriting a file in place is a new image; the old journal is preserved, dormant and findable
  • Clock-shift detection: a DST-style mtime jump across the library updates timestamps in place instead of triggering a re-hash storm
  • Prioritized ingest queue with retries, poisoned-row rescue, and startup recovery - the queue is the truth, restarts just continue
  • Ingest honesty: the empty state says "scanning" with a live discovered count - never "No photographs" while work is pending [Jun 12]
Previews & metadata
  • Thumbnail + display preview cache (WebP), EXIF rotation applied, sRGB-converted - what you see is display-true [M1]
  • Fast first run via embedded RAW preview extraction, including the Sony chained-IFD sweep [M1] (partial: the full RAW-decode backfill is M1.5 - HEIC previews and true decoded 1:1 wait on it)
  • RAW deep zoom today via the embedded full-resolution JPEG, with strokes staying put at any zoom
  • EXIF subset read at ingest (date, camera, lens, exposure, GPS) - strictly read-only; the app never writes into image files [M1]
  • "Rebuild previews…" on any rail folder; preview-format upgrades regenerate automatically
  • Library doctor: a self-check pass that re-queues missing preview artifacts and sweeps stranded temp files - the library heals
Volumes & offline
  • Offline volumes are first-class: disconnected badge, cached thumbnails, journal intact and searchable; notes you make while offline queue and land on reconnect [M1]
  • Stable volume identity that survives remounts and recognizes clones; verified live on macOS
  • Read-only volumes are probed, not guessed; an offline volume never burns retry attempts
RAW+JPEG pairs
  • Auto-paired display stacks with live, reversible collapse/expand - per pair and globally
  • Annotating a collapsed stack targets both files in one event, so a note never hides on the member you aren't viewing
  • R flips the displayed member in Look
Capture - the journal
  • Typed quick notes bound to the current selection - press N or click the Station, type, Enter, gone [M1]
  • One remark can target all N selected images; session-level remarks need no image at all [M1]
  • Silent keyboard ratings 0–5 during culling - journal events, never file metadata; rating a multi-selection mints one event [M1]
  • Sessions are automatic and idle-segmented; crashed sessions are recovered cleanly at next launch - there is no session management [M1]
  • Append-only event log: nothing is ever silently edited or lost; merging machines or backups is a union by event id [M1]
  • Retraction ("strike that"): hidden everywhere but preserved in the log, with an Undo that re-states [M1]
  • True redaction: a two-step hold-to-confirm, then the content is physically scrubbed from database, search index, vectors, and sidecars - byte-scan proven [M1]
  • Transcript correction: edits are revision events - the corrected text is what's shown and searched, the original stays in the log [M2b]
  • Journal panel (J): verbatim chronological history under session dividers - edited folds, retracted behind a toggle, redacted stubs, stroke micro-previews; correct / retract / redact on every row [M2a]
  • Compose from the journal panel; jump from any entry back to selecting its target images
  • Write scope is derived from what you're looking at, never set by hand - and voice binds to the scope at the moment speech starts
Voice
  • Space is the microphone key: tap to toggle, press-and-hold for push-to-talk - one key, two gestures [Jun 12]
  • Real microphone chain: any input device, downmixed and resampled on a dedicated thread [M2b, live-verified]
  • In-process voice-activity gate with a 400 ms pre-roll, so first words are never clipped [live-verified]
  • Streaming local speech recognition (Nemotron via sherpa-onnx) in a supervised child process - fully offline [live-verified]
  • Utterances bind to the selection snapshot at speech onset: words follow your eyes even if you click away mid-sentence
  • Finals are edge-trimmed of tokenizer artifacts - the journal holds your words, not the model's word-boundary spaces [Jun 12]
  • The tail-truncation class was root-caused to the model export's baked-in lookahead and fixed by the 560 ms pin swap [Jun 12]
  • Audio is never written to disk: an in-memory ring only, zeroed on disarm and quit
  • If speech recognition dies, it degrades quietly: nothing half-minted, the mic disarms with a quiet glyph, typed notes are untouched, supervision brings it back
  • ASR resilience: a plan that says "run" with a missing binary is surfaced instead of spinning, and the dev pipeline builds the speech server [Jun 12]
  • Voice notes get an edge trim so what lands in the journal starts and ends on your words [Jun 12]
Grease pencil
  • B picks up the red pencil on the single-image view; every stroke is one journal event [M2a]
  • B with the tracing paper hidden shows the paper AND arms the pencil in one keystroke - a bound key is never dead [Jun 12]
  • Tracing-paper overlay toggle (O): marks on or off, the image untouched beneath [M2a]
  • Strokes survive pan, zoom, and orientation - normalized coordinates round-trip to within one source pixel
  • Pressure-aware stroke width where hardware provides it (partial: logic-tested; real-stylus feel is still an open founder item)
  • Undo is a retraction (Cmd/Ctrl+Z, ten deep) - nothing is deleted, ever
  • Eraser: hold E or flip the stylus, tap to retract a whole stroke
  • Strokes and words spoken in the same moment link to each other, both ways [M2b]
Main-flow UI
The shell
  • Three surfaces - thumbnail grid, single-image Look, search - and that is the whole app [M1]
  • Panel-system layout: drag-resizable rail, inspector, and filmstrip arranged around a centered canvas, all sizes persisted [Jun 12]
  • Tab is lights-out with snapshot-restore: all chrome vanishes, Tab again brings back exactly what you had; F totals the filmstrip [Jun 12]
  • Capture is ambient: no live transcript pane, no composer chrome, no metadata editing UI anywhere [M1]
  • Keyboard-first throughout: Esc always backs out exactly one layer and never quits; G goes home from anywhere; every key means the same thing everywhere
Grid
  • Virtualized thumbnail browsing that stays smooth while ingest populates it live; image bytes never cross IPC [M1, live-verified]
  • Selection as you expect it: click, Shift-range, Ctrl-toggle, marquee from the gutter, full keyboard; active-vs-selected follows the pro-tool convention
  • Scroll is anchored to the image, not the offset - a mid-ingest re-sort never yanks the viewport
  • Thumbnail badges stay quiet: only the has-journal dot and the offline-volume badge, ever; T cycles cell info
  • Sort per folder (capture date, filename, date added), four thumbnail sizes, Ctrl+wheel sizing
  • Recycled cells can never flash the previous image's pixels
Look
  • Edge-to-edge image; wheel zoom-to-cursor, Z fit/100%, Space holds-to-pan while zoomed, zoom state persists across prev/next
  • Prev/next walks the grid or search-result order; entering with a multi-selection cycles within it
  • Filmstrip scrolls the whole order with the selected photo centered, virtualized; it pushes the canvas up rather than covering it [Jun 12]
  • Right inspector: read-only Metadata tab (I) and the Journal tab (J), pushed not overlaid, persisted
  • Auto-advance (A): rate, advance, rate - the culling heartbeat, default off, persisted
  • Surround luminance: black through white behind the image, chrome stays dark and quiet

  • Every commit pulses the Station - notes, strokes, ratings land with feedback but no interruption
  • While an utterance started under an earlier selection is still streaming, the Station shows the bound scope with a tether mark
  • Click feedback everywhere: a global pressed state, and fire-and-forget verbs acknowledge with a flash at the control [Jun 12]
  • Copy actions confirm themselves at the affordance - icon flips to a check only after the clipboard write lands
  • The titlebar shows one dim word ("digesting") while background work is queued, with the breakdown on hover - every background job flows through one register
  • Toast discipline: exactly two toasts exist in the whole app - retraction (with Undo) and redaction-completed
  • First run opens straight into the working app: the welcome card explains where your data lives, the consent card offers models with a live byte sum, and features light up silently as services come ready [live-verified]
Search & retrieval
  • Instant keyword search over notes and transcripts, search-as-you-type, millisecond-grade at a million rows - works with zero models installed [M1]
  • Filter chips as hard constraints: date (captured vs annotated), camera, lens, folder, rating (an explicit 0 is not "unrated"), has-strokes, volume, collection - all combinable
  • Every result shows why it matched: your own quote, highlighted and dated, with session context - never machine prose [M3]
  • Hybrid semantic search: your words as vectors plus image content, fused so your words always outrank machine impressions; byte-identical to keyword search when no models are present [M3] (partial: proven end-to-end with the real models in tests; live in-app use is the founder dogfood gate, and the natural-language parse is not yet wired to the live model)
  • Search never errors: a failing embedder, a damaged vector file, or a bad parse all degrade silently to keyword results
  • The hallucination firewall drops exactly the invalid parse clauses, with debug-visible reasons, and runs the rest
  • Local vector store (PPVEC): compact int8 flat file, crash-atomic compaction, and redaction zeroes the stored bytes before the call returns
  • Embedding backfill rides the ingest queue politely - only when ingest is idle and the mic is off
  • Search lives in an overlay floating over the dimmed canvas; results fill the canvas as they arrive; Enter opens Look with result order driving prev/next
Collections
  • Named collections with evented membership - "tags with time": when something joined or left is queryable history [M3]
  • Rail Collections tab beside Folders: create, click to view members; add and remove membership from any image's context menu
  • Collections carry their own append-only notes - about the grouping's intent, not any one image (partial: storage and commands landed; the composer UI is pending)
  • Fully portable: a collections sidecar file with union merge, included in export, consumed by rebuild
  • A collection chip in search constrains to current members, with fuzzy name resolution that needs no models
Persistence & portability
  • A .photoproof.json sidecar beside every annotated image, written within seconds - the sidecars ARE the data; walk away anytime [M1]
  • Atomic, mtime-stable writes: identical content never touches the file; kill the app mid-write a thousand times and nothing corrupts
  • Overflow store (same format) for read-only volumes, migrating back beside the images when the volume becomes writable
  • SQLite is just a rebuildable index: delete it, rebuild from sidecars, get a byte-identical event set back - seconds at 50k events [M1]
  • Merge is a union by event id: second machines, restored backups, and re-found sidecars simply merge - and redactions always win, even against a pre-redaction backup
  • Separated sidecars re-match: orphans, regenerated files, stale subsets, even two swapped images keep both their journals
  • Unknown fields and newer-schema files are preserved untouched - a future version's data is never damaged by an old build
  • One-click full export: the complete sidecar set, session journals, and a manifest - identical to rebuild input [M1] (partial: the export note doesn't yet say how many journals exist only in overflow)
Models & runtime
  • Local-first, network-never: the free tier makes no network calls except model downloads - SHA-pinned, license-gated, consent-gated before the first byte [live-verified]
  • The no-models mode is a complete product: notes, pencil, ratings, sessions, sidecars, and keyword search on any machine [M1]
  • Model downloads: resumable and checksummed, with model-cumulative progress, a resume baseline, and auto-retry on interruption [Jun 12]
  • Hardware tier detection with a one-time quiet proposal; the user's override always wins (partial: the Windows detection path is compiled but never exercised)
  • Supervised child processes: health probes, restart backoff, orphan sweep, single-instance lock - children die with the parent, no zombies
  • Streaming-ASR child (pp-asr-server) - live and founder-verified; language-model child (llama-server) supervised and ready (partial: no shipped feature consumes LLM completions yet)
  • In-process embedders via ONNX Runtime: EmbeddingGemma for your words, DFN5B CLIP for the images - pinned SHAs, proven end-to-end against the real weights
  • Installed-model rows in Settings show running/idle state; the degraded explainer says what works without them
  • Every model sits behind a trait seam - swapping a model is a manifest pin, never a rewrite
